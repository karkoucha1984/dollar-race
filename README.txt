خطوات النشر (مجاناً):
1. افتحي الموقع app.netlify.com/drop
2. اسحبي هذا المجلد كله (أو ملف ZIP) إلى الصفحة.
3. سيعطيك Netlify عنوان https. افتحيه على الجوال.
4. أندرويد (Chrome): القائمة ⋮ ثم «تثبيت التطبيق».
   آيفون (Safari): المشاركة ثم «إضافة إلى الشاشة الرئيسية».
5. افتحي اللعبة مرة واحدة وأنتِ متصلة بالإنترنت، وبعدها تعمل بدون إنترنت.
